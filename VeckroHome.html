Questions

Answers, quickly.

Everything you might want to know before you open the studio for the first time.

Is Veckro really free?
Yes. The full application — every panel, every preset, every export option — is free and open source under the MIT licence. There is no paid tier, no watermark on your exports, and no account required.
Do my photos get uploaded anywhere?
No. Veckro runs entirely inside your browser using the HTML canvas API. Your images are read from your device, processed in memory and written back to your device. Nothing is ever sent to a server — which also means the studio works perfectly offline.
Which file formats can I open and export?
You can open any format your browser can decode — JPEG, PNG, WebP, AVIF, GIF and more. Exports can be written as PNG, JPEG, WebP, AVIF or TIFF, with optional DPI tagging, watermarking and copyright metadata.
Will it run on my machine?
If your browser can display a modern website, it can run Veckro. On first launch you choose a preview resolution and a render delay — pick "Fast / 540p / Instant" on older hardware, or "High / 1440p" on a modern workstation. You can change these at any time from the settings button.
Can I save my work between sessions?
Yes. Use "Save Project" to write a small JSON file containing your full grade, layers, masks, node graph and settings. Loading it restores the exact state. The app also autosaves to local storage every 20 seconds so a refresh never loses your work.
Does it replace Lightroom or Capture One?
For colour grading, retouching, film looks and LUT work — yes, comfortably. Veckro is not a full digital asset manager, so it does not replace a catalogue or a RAW library. Many people use it alongside one: catalogue in your DAM, grade in Veckro.
Can I use the .cube LUTs elsewhere?
Absolutely. Any look you build can be baked out as a 33³ .cube LUT and loaded into Resolve, Premiere, Final Cut, Affinity Photo or any other application that reads the format. The Color Match panel can even generate a LUT from a reference photograph.

Get Color Studio

The whole studio is a single HTML file: copy it, save it, open it. No install, no account, no upload.

Free to use. Open source under the MIT licence.

  • Personal and commercial use allowed
  • Read, fork and modify the source

0.0.0-beta is the first public release. The core studio is usable, but expect rough edges. A finalized release will follow.

1Copy the code

veckro-color-studio-0.0.0-beta.html

2Save it as an .html file

Paste the code into any text or code editor and save it as veckro-color-studio.html. The .html ending matters. If you tapped Download .html, skip this step.

3Open it on your device

Android phone or tablet
  1. Install a free editor such as Acode, Markor or QuickEdit.
  2. Paste the code and save it as veckro-color-studio.html in Downloads.
  3. Open Files → Downloads, tap the file and choose Chrome. If it shows as plain text, type file:///sdcard/Download/veckro-color-studio.html into Chrome, or use Termux below.
  4. In Chrome, tap ⋮ then Add to Home screen for an app-style shortcut.
Android with Termux (most reliable)

Save the file in Downloads, then run this in Termux. Allow storage access when asked.

termux-setup-storage
pkg install python
cd ~/storage/downloads
python -m http.server 8080

Open http://localhost:8080/veckro-color-studio.html in Chrome.

iPhone and iPad
  1. Tap Download .html and save it to Files, or paste the code into an editor such as Textastic or Documents by Readdle.
  2. Open the file in an app that can show local HTML, for example Documents by Readdle.
  3. For a normal Safari experience, upload the file as index.html to a free GitHub Pages site, open the link in Safari, then tap Share → Add to Home Screen.
Windows, macOS and Linux

Save the file, then double-click it or drag it into Chrome, Edge, Firefox or Safari. It works offline.
